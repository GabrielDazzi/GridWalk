# Security Policy

## Supported versions

Security fixes target the latest release on `main`.

## Reporting a vulnerability

Please **do not** open a public issue for security bugs.

Report it privately through GitHub instead: open the repo's **Security** tab and click **Report a vulnerability** ([direct link](https://github.com/GabrielDazzi/GridWalk/security/advisories/new)). Include:

- A short description of the issue
- Steps to reproduce
- Impact (e.g. sandbox escape, data leak)

We will acknowledge receipt and work on a fix before any public disclosure.
